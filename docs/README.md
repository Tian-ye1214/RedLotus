# RedLotus 项目总览

RedLotus 是以终端为主要入口、围绕本地项目工作的个人 AI Agent。用户通过自然语言提出目标，Agent 使用工具、委派子任务、调用 Skills，并通过项目记忆和长期记忆延续工作。

项目以用户打开的文件夹为工作边界，不向父目录查找项目。任务结果由实际文件、工具回执、引用来源、任务状态和可恢复的会话共同呈现。QQ、微信适配器复用同一会话系统，并按渠道身份限制权限。

## 能力概览

| 能力 | 功能 |
| --- | --- |
| 对话与任务 | Coordinator 直接执行，或委派 Worker、Manager 处理子任务和依赖计划；goal 模式维护持续目标 |
| 工具与 Skills | 文件读写、命令执行、网页搜索、文档解析、浏览器、图像生成和按需加载技能 |
| 引用与审查 | 本地文件和图片引用、不可变引用快照、文件变更展示、逐块决定与撤销 |
| 输入与控制 | 普通输入排队、加急补充、停止、暂停、明确恢复、会话加载和项目切换 |
| 上下文与记录 | 角色独立上下文、模型容量管理、持久化恢复、调用轨迹和用量查询 |
| 感知与记忆 | 按会话窗口生产项目记忆，按授权生产长期记忆，支持搜索、更新、遗忘和索引恢复 |
| 渠道接入 | QQ、微信的身份绑定、附件准备、输入排队和回复适配 |

角色权限和工具集合见[Agent 与工具边界](design.md#agent-与工具边界)。浏览器、机器人及部分文档处理依赖相应服务或可选组件；工具层保护不提供操作系统级沙箱隔离。

## 运行入口

| 方式 | 入口 | 本地配置查找基准 |
| --- | --- | --- |
| 源码 | `python main.py` | 源码仓库根目录 |
| pip 安装 | `redlotus`，入口函数为 `redlotus.api.base:main` | 启动时的工作目录 |
| PyInstaller | onedir 或 onefile 的 `Agent.exe` | EXE 所在目录 |

项目要求 Python 3.12 或更高版本。源码和 pip 的 Python 工具使用启动解释器；EXE 的 Python 工具使用 PATH 中的外部 Python。应用不自动创建虚拟环境，EXE 缺少外部 Python 时无法执行依赖它的工具。

连接配置沿用[三层逐字段读取规则](design.md#模型配置与上下文)。首次引导处理 API Key、Base URL 和已配置角色的模型选择；可选能力在使用时读取所需配置。随包资源目录与用户业务配置目录分开，onefile 的临时解压目录不作为业务配置来源。

## 数据归属

| 归属 | 内容 |
| --- | --- |
| 项目 `.redlotus` | 主会话及角色记录、会话索引、感知进度、项目日志和 `AGENT.md` |
| 项目 `WorkDatabase` | 任务产物、引用快照、执行缓存、临时文件和用户 Skills overlay |
| 用户 `~/.redlotus` | 全局配置、LanceDB 记忆库及 `LongTermMemory/MEMORY.md` 投影 |

表中是项目的数据布局；实际存储路径由既有配置和显式路径入口解析。项目级存储必须位于当前工作区内，L1 记忆按项目隔离，L2 记忆在本人权限范围内跨项目使用。

会话事务、暂停恢复、日志与空间清理的规则集中在[会话与数据存储](design.md#会话与数据存储)，配置及测试数据的保护要求集中在[开发约定](development.md#配置与凭据)。
