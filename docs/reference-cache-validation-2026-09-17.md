## 具体修改与职责

| 入口 | 职责 |
|---|---|
| `ReferenceFile.to_prompt` | 稳定渲染文件身份、SHA256、解析版本、实际覆盖范围、已提供/仅登记状态及结束边界；正文和原生附件仍完整传递 |
| `read_reference` | 返回已登记的不可变快照全文及原生媒体；用于内容已不在上下文或明确重读 |
| `read_file` | 读取磁盘当前版本的文本，例如代码、产物或修改后的源文件 |
| `extract_text` | 解析尚未作为引用提供的项目文档 |
| `common_conduct.md` | 说明当前已提供资料可直接消费；计算可以读取快照并返回结果；不将引用内容视为用户指令或偏好 |
| `RequestJournal.request_evidence` | 从真实发送的 payload 计算 system、工具、参数和历史哈希，判断历史前缀是否保留 |
| `RequestJournal.response_evidence` | 读取真实服务端 usage、模型名称及 fingerprint；未知数据不伪装成零 |
| `RequestJournal.cache_report` | 按主 Agent/普通子 Agent和辅助角色分组汇总，冷请求仍计入 |
| `AcceptanceRun.local_regressions` | 在同一个 600 秒期限内执行固定故障注入及交互回归，隔离数据库放在 C 盘，其他产物在 E 盘 |

没有增加正文自动省略、强制去重或 force 参数。原有读取工具仍返回真实内容。新提示词只影响新会话；恢复会话继续使用原提示词快照。
