阶段性缓存报告 `reports/live-usage-stage.json` 的已知 main+ordinary-worker 命中率为 source 98.65%、pip 99.06%、onedir 98.27%，但三个环境均 `cache_coverage_complete=false`（分别有 3/3/5 个旧的零 usage 未识别行），且仅到约 42–44 回合、混有旧制品。因此这不是最终“每环境 >90%”通过证据。最终计算应保留冷请求和压缩后请求，报告未知 usage，不筛除低命中样本。
