# 感知、工具权限与退出修复验收

实现分支：`codex/real-world-evaluation`。本轮沿用实际配置的模型、embedding、reranker 与上下文阈值。证据保留在本机 `WorkDatabase/evaluation/perception-fix-20260914-105751/`，原始对话、失败输出和测试资料不上传 Git。

最终辅助回归 **196 passed in 173.33s**，无测试告警。复核修复后又执行三轮真实模型请求：由子 Agent 在新项目创建环境并运行统计脚本，taskkill 与直接导入的 `kill` 都被工具拒绝，HTTP 测试服务保持存活，退出耗时 0.055 秒；该轮没有非预期 WARNING/ERROR。详细结果见 `evidence/merge-final-tests.txt` 与 `evidence/tool-auth-exit-final/`。

## 实现范围

- 感知每窗消费 20 个新增 user-assistant 回合，附带 3 回合衔接。工具、子 Agent 内部轮次和当前回合的加急输入不另计数。
- 每窗只执行一个完整感知任务；主动检索已有情景、更新原 ID；移除独立分片摘要生产。保存配置/证据快照、生产结果、检索和阶段耗时，生产与索引重试分离。
- 子 Agent 的命令和 Skill 脚本共用工具权限检查；运行时保留自有命令的取消与进程树回收。没有使用 Windows 权限库、账户隔离或系统 Hook。
- 退出封存未完成窗口，取消任务并释放资源，不等待模型产出。CLI/TUI 首次调用 shutdown 时启动配置中的退出限时；阻塞线程不响应取消时结束当前应用实例。
- Python 环境创建使用可取消的异步进程入口，记录解释器与 pip 的创建阶段，中断后继续。命令参数、环境来源和路径规则继续来自配置。

## 失败与修复记录

- Windows 受限令牌原型未通过验证，已经退出正式源码；用户后续明确选择工具层权限，不再采用该方案。
- 原生命令可执行的 cmd 嵌套引号被预检查误拒，已修复并由模型原样重放成功。
- 首次 venv 创建的取消会等待阻塞线程；已改用公共异步进程入口，并验证中断后继续创建。
- 原退出限时在外层入口启动过晚，可能绕不到 TUI 内部 shutdown；已移到统一 shutdown 首次调用处。
- 快速退出暴露了 TUI 状态刷新在控件拆除后仍查询界面的竞态；已按应用生命周期停止刷新，并纳入最终回归。
- 首次情景中有过时的待确认阈值，后续窗口在原记录上清理；CSV 首次交付失败与修复后的输出均保留。
- 60 回合期间出现一次 DuckDuckGo 请求失败，原日志保留；不能称该整个长会话全程零 ERROR。工具权限/退出的专门真实测试没有非预期 WARNING/ERROR，权限拒绝按预期负例记录。
